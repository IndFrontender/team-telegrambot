# team-telegrambot
# Telegram Task Bot

Бот для управления личными и командными задачами в Telegram.

## Особенности

- Управление личными задачами
- Интерактивное меню с кнопками
- SQLite база данных
- Модульная архитектура с использованием ООП
- aiogram 3.x
- Поддержка прокси для работы через VPN

## Структура таблицы БД

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Primary Key, автоинкремент |
| text | TEXT | Текст задачи |
| user | INTEGER | ID пользователя Telegram |
| created_at | DATETIME | Время создания задачи |

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Настройте переменные окружения:
   - Скопируйте `.env.example` в `.env`
   - Замените `YOUR_BOT_API_TOKEN_HERE` на токен от @BotFather

```bash
cp .env.example .env
```

## Запуск

```bash
python bot.py
```

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и инструкция |
| `/add <текст>` | Добавить новую задачу |
| `/list` | Показать все задачи |
| `/delete <номер>` | Удалить задачу по номеру |

## Интерактивное меню

Бот работает через кнопки:

**Главное меню:**
- 📝 Мои задачи — показать список
- ➕ Добавить задачу — создать новую
- 👥 Командные задачи — (в разработке)

**Меню задач:**
- 📋 Список задач
- 🗑 Удалить задачу
- 🔙 Главное меню
